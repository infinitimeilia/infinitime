# InfiniTime

[فارسی](README.md) · [العربية](README.ar.md)

An Android clock, calendar and time-planning app supporting Persian, English and Arabic.

Features include alarms, world clocks, timer, stopwatch, Persian/Gregorian/Hijri calendars, notes and reminders, prayer times, adhan, compass, qibla and widgets.

## Download

[Latest published release](https://github.com/infinitimeilia/-infinitime/releases/latest)

Download **InfiniTime.apk** from the release assets. Requires Android 8.0 or later. Open the APK in your file manager and approve installation yourself. Updates must use the same signing key as the installed production app. No download exists until the first release is published.

This repository distributes releases; it does not contain the development source or private signing keys. In app versions configured for this channel, update checks run only while the app is open, and APK downloads require an explicit user action.
