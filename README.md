# InfiniTime

[English](README.en.md) · [العربية](README.ar.md)

برنامهٔ اندرویدی ساعت، تقویم و برنامه‌ریزی زمان با پشتیبانی از فارسی، انگلیسی و عربی.

- ساعت و هشدار، ساعت‌های جهانی، تایمر و کرنومتر
- تقویم شمسی، میلادی و قمری، یادداشت و یادآوری
- اوقات شرعی و اذان، قطب‌نما و قبله‌نما، ویجت‌ها

## دریافت برنامه

[مشاهدهٔ نسخه‌های منتشرشده و دانلود](https://github.com/infinitimeilia/-infinitime/releases/latest)

از بخش **Assets** فایل `InfiniTime.apk` را دریافت کنید. اگر هنوز نسخه‌ای منتشر نشده، این لینک فایل دانلودی ندارد.

حداقل نسخهٔ اندروید: **۸٫۰**. فایل APK را خودتان در فایل‌منیجر باز کنید و نصب را تأیید کنید. نصب خودکار انجام نمی‌شود. برای به‌روزرسانی نسخهٔ قبلی، APK باید با همان کلید امضای قبلی امضا شده باشد.

این مخزن مخصوص انتشار نسخه‌های برنامه است؛ کد توسعه و کلید امضا در این مخزن قرار نمی‌گیرند.

## سازوکار به‌روزرسانی

نسخه‌های متصل به این کانال، هنگام باز شدن برنامه و وجود اینترنت، اطلاعات کوچک نسخه را بررسی می‌کنند. دانلود APK فقط با انتخاب کاربر انجام می‌شود. متن قابلیت‌های جدید از اطلاعات همان Release خوانده می‌شود.
