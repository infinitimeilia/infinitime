# InfiniTime

[فارسی](README.md) · [English](README.en.md)

تطبيق أندرويد للساعة والتقويم وتنظيم الوقت، مع دعم الفارسية والإنجليزية والعربية.

يتضمن المنبهات والساعات العالمية والمؤقت وساعة الإيقاف والتقاويم الفارسي والميلادي والهجري والملاحظات والتذكيرات ومواقيت الصلاة والأذان والبوصلة والقبلة والأدوات المصغرة.

## التنزيل

[أحدث إصدار منشور](https://github.com/infinitimeilia/-infinitime/releases/latest)

نزّل **InfiniTime.apk** من ملفات الإصدار. يتطلب أندرويد ٨٫٠ أو أحدث. افتح الملف في مدير الملفات ووافق على التثبيت بنفسك. يجب توقيع التحديث بمفتاح توقيع الإصدار المثبت نفسه. لن يتوفر التنزيل قبل نشر أول إصدار.

هذا المستودع مخصص لتوزيع الإصدارات، ولا يحتوي على شيفرة التطوير أو مفاتيح التوقيع الخاصة. في الإصدارات المتصلة بهذه القناة، يتم التحقق من التحديثات أثناء فتح التطبيق فقط، ولا يبدأ تنزيل APK إلا باختيار المستخدم.
